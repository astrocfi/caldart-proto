===========================
Website administrator guide
===========================

For website administrators: using the Wagtail admin to add, edit, reorder,
preview, publish and delete pages, work with the StreamField blocks, manage
images and documents, mark pages members-only, and change the site settings
(contact details, donate link, theme, footer).  This page will be written on
``feat/docs`` in Phase 3, documenting the CMS delivered by ``feat/cms-site``.
