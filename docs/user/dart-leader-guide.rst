DART leader guide

For DART leaders: the pre-flight check.  How to search for a member by name,
email or N-number, read the status card (membership current? medical current?
insurance current on the aircraft being flown?), and interpret the go / no-go
summary.  This page will be written on ``feat/docs`` in Phase 3, documenting
the leader tooling delivered by ``feat/aircraft-leader``.
