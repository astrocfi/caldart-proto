======================
Choose a new password
======================

The **Choose a new password** screen is where the link in a password email takes
you. You set a new password here, and then sign in with it.

You reach it two ways:

* from the email *CalDART: reset your password*, which you asked for on
  :doc:`forgot-password`, or a user administrator sent you;
* from the email *CalDART: set your password*, which arrives when an account
  administrator creates an account for you. It says an account has been created,
  registered to your address, and asks you to choose a password to finish setting
  it up.


What you see
============

Pick something you do not use anywhere else. The screen has two boxes:

**New password**
  At least eight characters, and not a password you have used elsewhere.

**Repeat new password**
  The same password again, so a typing slip does not lock you out.

Press **Save new password**. **Request a new link** goes back to
:doc:`forgot-password`.


What happens next
=================

The screen changes to **Password changed**: *Your new password is saved. Sign in
with it to get back to the portal.* Press **Go to sign in** and sign in with the
new password (see :doc:`sign-in`).

Setting the password also confirms your email address, since the link could only
have reached you there. If the account was deactivated, it is active again.


Password rules
==============

CalDART turns down a password that is:

* shorter than eight characters;
* one of the twenty thousand most common passwords;
* entirely numbers;
* too like your own name or email address.

The message under the box says which rule the password broke. Nobody at CalDART
can see your password or tell it to you, because it is never stored in a form
anyone can read.


If the screen says something else
=================================

*The two passwords do not match.*
  The two boxes differ. Type both again.

*That password reset link is invalid or has expired. Request a new one.*
  The link has been used already, or it is more than three days old, or it was cut
  short when it was copied. Press **Request a new link**.

**That link is incomplete.**
  The address you opened is missing part of the link. Open the link from the email
  exactly as it arrived, or ask for a new one.


If something looks wrong
========================

If every link you try comes back invalid, ask for one fresh link and use it
straight away, from the same browser. If that fails too, ask a user administrator
to send you a reset link from your user record.
