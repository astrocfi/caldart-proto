===================
Editing the website
===================

These pages cover the public website's pages, members-only area, settings, and themes,
which you edit in the website's own editor.

The editor is Wagtail, and it opens at the site's own address followed by /admin/, such
as caldart.org/admin/. Sign in with the same email address and password you use for the
member portal. It is the same account, so if you are already signed in to the portal, the
editor opens without asking again. Your account needs the website administrator role, and
a user administrator can add it.

Everything in the member portal, such as members, payments, and reports, belongs to other
roles, and they edit it in the portal. That includes accounts and roles: the editor doesn't
have the Users or Groups screens, and its Account link opens your portal profile. A user
administrator adds or removes roles on the portal's :doc:`../admin/users` screen.
