===================
Editing the website
===================

The public website's pages, members-only area, settings, and themes, edited in the website's own editor.

The editor is Wagtail, and it opens at the site's own address followed by /admin/, such
as caldart.org/admin/. Sign in with the same email address and password you use for the
member portal. It is the same account, so if you are already signed in to the portal the
editor opens without asking again. Your account needs the website administrator role;
a user administrator can add it.

Everything the member portal holds, such as members, payments, and reports, belongs to
other roles and is edited in the portal.
