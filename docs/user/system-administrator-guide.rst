==========================
System administrator guide
==========================

For system administrators: the ``/portal/system`` screen -- health checks,
taking and downloading database backups, and triggering the renewal-reminder
scan by hand -- plus managing users and roles and knowing when to escalate to
the developer guide.  This page is owned by ``feat/ops``, which delivers the
``sysadmin`` and ``reminders`` apps, and is finished on ``feat/docs``.
