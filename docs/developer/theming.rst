=======
Theming
=======

The design system: the semantic CSS custom properties in ``tokens.css``, the
three shipped themes (``sierra``, ``pacific``, ``night``), how a website
administrator switches theme from Wagtail Site Settings, how the chosen theme
reaches the page as ``data-theme``, and how to add a fourth theme without
touching any component.  This page is owned by ``feat/cms-site``, which
delivers the public site templates and the site settings that select it.
