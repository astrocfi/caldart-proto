=================
Development setup
=================

Getting a working checkout: prerequisites (Python 3.12, ``uv``, Node, Docker),
``make setup``, bringing up Postgres and Mailpit with ``make up``, migrating
and seeding, running Django on :8000 alongside the Vite dev server on :5173,
and the demo accounts to log in with.  This page will be written on
``feat/docs`` in Phase 3, from the Makefile targets in PLAN §14.
