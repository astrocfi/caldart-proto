Configuration
=============

Every environment variable in ``.env.example`` -- database, secret key, hosts,
site URL, email, payment provider keys, mock-payments switch, Vite dev mode,
backup location -- what each one does, and which of the ``base``, ``dev``,
``prod`` and ``test`` settings modules reads it.  This page will be written on
``feat/docs`` in Phase 3, against the variable list in PLAN §14.
