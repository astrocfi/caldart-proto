=============
API reference
=============

The ``/api/v1/`` contract endpoint by endpoint: authentication and CSRF,
pagination and filtering conventions, error shapes, and every route for auth,
users admin, profile, members admin, aircraft, the leader check, payments,
reports, reminders and system operations, with the role each one requires.
This page is owned by ``feat/docs`` in Phase 3, consolidating the per-branch
endpoints against PLAN §5 and §6.
