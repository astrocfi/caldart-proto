==============
Payments setup
==============

Setting up the payment providers: creating Stripe and PayPal accounts, where
to find the publishable / secret keys and the webhook signing secret,
registering the domain for Apple Pay and serving the merchant-id association
file, what Google Pay needs (nothing extra in test mode), the test cards and
sandbox buyer accounts, and how to work with the ``mock`` provider when you
have no keys at all.  This page is owned by ``feat/payments``.
