=======
CalDART
=======

CalDART is the website and member management system for |org|, a 501(c)(3)
that organises California pilots and ground personnel to provide volunteer
disaster air transportation.  These pages are in two halves: a **user guide**
for members, DART leaders and the various administrators who run the site day
to day, and a **developer guide** covering the architecture, local setup,
configuration, APIs, theming, testing and deployment of the system itself.
This documentation set is a skeleton created on ``feat/foundation``; each
Phase 2 branch fills in the pages it owns (PLAN §17).
